📖 Glosario de E-R

Entidad

Objeto o concepto del mundo real del que se guarda información. Ej: CLIENTE, AUTO, PRODUCTO.

Relación

Vínculo o acción entre dos o más entidades. Suele ser un verbo. Ej: tiene, realiza, recibe.

Atributo simple

Dato que describe a una entidad o relación. No se puede dividir. Ej: nombre, fecha, precio.

Atributo clave (PK)

Identifica de forma única a cada instancia de una entidad. Se subraya. Ej: CI, Id_cliente, Isbn.

Atributo multivaluado

Puede tener varios valores para la misma entidad. Se dibuja con doble borde. Ej: Teléfonos, Actores.

Atributo compuesto

Se puede dividir en partes más pequeñas. Ej: Nombre_completo → Primer_nom + Primer_ape.

Atributo de relación

Describe información propia del vínculo entre entidades. Se conecta al rombo. Ej: Fecha_entrada en la relación "recibe".

¡Bienvenido a E-R Constructor!

Esta herramienta ayuda a practicar el Modelo Entidad-Relación paso a paso. Tiene 3 etapas que guían desde leer el problema hasta el pasaje a tablas.

📋

Etapa 1: Analizar

Leer el enunciado del problema. A la derecha aparecen fichas con los términos importantes.

Hacer clic en cada ficha y clasificarla como Entidad, Atributo o Relación. Luego presionar Validar clasificación.

Se puede consultar el ante dudas.

🔗

Etapa 2: Diseño E-R

El diagrama tiene huecos en blanco. A la izquierda hay un banco de palabras.

Hacer clic en una palabra del banco y luego en el hueco donde corresponde. Al terminar, presionar Corregir Diagrama.

También se puede subir una imagen MER como referencia con el botón "Subir MER de referencia".

📊

Etapa 3: Pasaje a Tablas

  • • Completar las tablas de entidades con el banco de palabras.
  • • Seleccionar la regla de pasaje para cada relación.
  • • Escribir las restricciones FK en el esquema final.
  • • En el botón ⊙ del menú se puede activar alto contraste.
